# NeoForge 26.1.2 / 26.1.2.94 compatibility adapter

This adapter is the only maintained migration target after the proven
NeoForge 1.21.1 baseline. It is composed with the loader-independent core and
is validated against the exact NeoForge 26.1.2.94 toolchain and the audited
26.1.x AE2 and Refined Storage API lines.

The adapter is `released` for the ImmortalStorage 0.1.5 line after its complete
source migration, compatibility probes, target contract suite, production JAR
boundary and exact-artifact checks. The version manifest records the line as
released and published.
Mekanism and EMI remain optional and excluded until official 26.1.2 API
artifacts are published. Only the two maintained version profiles are release
inputs.
