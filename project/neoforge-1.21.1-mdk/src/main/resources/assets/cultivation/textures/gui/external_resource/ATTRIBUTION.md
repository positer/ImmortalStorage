# Bundled AE2 Addon Resource Icons

- `ae2_fe.png`: Applied Flux 2.1.5, `assets/appflux/textures/energy/fe.png`, LGPL-3.0 distribution metadata; original texture credit in the mod metadata: Ridanisaurus.
- `ae2_chemical.png`: Applied Mekanistics, `chemical_storage_cell_1k.png`, LGPL-3.0 source archive.
- `ae2_botania_mana.png` and `.mcmeta`: Botania `block/mana_water`, the exact atlas sprite selected by Applied Botanics' `ManaRenderer`; Botania assets and Applied Botanics assets are CC BY-NC-SA 3.0.
- `ae2_ars_source.png` and `.mcmeta`: Ars Nouveau `block/mana_still`, the exact atlas sprite selected by Ars Energistique's `SourceRenderer`; Ars Nouveau and Ars Energistique license metadata are archived with the source references.

These files are bundled under the Cultivation namespace so the storage UI and Cultivation-owned AE2 keys retain the same visual identity when the corresponding addon is not installed. They remain unmodified reference assets; no runtime dependency on the source addon namespace is created.
